How to Back Up and Restore AAC Communication Boards

Simple steps to save someone's communication boards and bring them back on a new or replacement device.

Why make a backup?

A communication board can include someone's words, photos, and recorded messages. A backup is a saved copy, so you can bring those boards back if a device is lost, damaged, replaced, or reset.

Make a backup after important changes and before replacing or resetting a device. Keep a copy somewhere other than the device, so it is still available if the device is lost.

Choose the right kind of backup

There are two ways to save boards:

  • Save everything: Choose Settings → Backup & Settings → Export Backup. This saves the app's boards and available photos and recordings in one file.
  • Save one person's boards: Choose Settings → Profiles → Export Boards. This saves the boards in the profile you are using. It does not change the settings on the device receiving the boards.

Saved files work across supported Apple, Android, and Amazon Fire devices that have the app. To bring everything back, use Import Backup. To bring back one person's boards, use Import Boards on the Profiles screen.

Save a copy of everything to a file

  1. Open Settings → Backup & Settings.
  2. Tap Export Backup and wait for the app to prepare your saved copy.
  3. When asked, save or share the file somewhere you can find it again, such as another device or a trusted cloud storage account.

The saved file may contain personal words, photos, and recordings. Share it only with people you trust.

Bring everything back from a saved file

  1. On the device where you want the boards, open Settings → Backup & Settings.
  2. Tap Import Backup.
  3. Choose the saved backup file and wait for the app to finish.

Restoring a full backup replaces the boards on that device. If you need to keep them, save a copy first.

Use cloud backup across devices

Cloud backup is a Premium feature. You need to create a cloud account before using it. Use the same account on every device where you want to save or restore boards. Repeat the sign-in steps on each device.

  1. On the first device, open Settings → General and turn on Enable cloud save/restore.
  2. Tap Log in to enable cloud sync, then choose Create Account. Enter your email address and choose a password. Keep these details safe.
  3. Go to Settings → Backup & Settings and tap Export Backup to save your backup to your cloud account.
  4. On another device, turn on Enable cloud save/restore in Settings → General. Go to the sign-in screen and log in with the same email address and password you used to create the account.
  5. On that device, open Settings → Backup & Settings, tap Import Backup, and confirm the restore.

Restoring replaces the boards on the device. Save a copy of any boards already on it if you want to keep them. On the web version, use a saved backup file to restore.

Share a patient's boards (for SLPs and SLTs)

Make a separate profile for the patient, so their boards stay separate from your own.

  1. Open Settings, tap the person icon to open Profiles, and create a profile for the patient. Switch to it and make the boards you want to share.
  2. Tap Export Boards. The app saves the boards in that profile to a file. The patient's device settings, such as language, voice, and display choices, are not changed when the boards are imported.
  3. Send the file to the patient or caregiver using a method available to both of you, such as Bluetooth, Dropbox, or email. Only send it to the intended person.
  4. On the patient's device, save the file. In the app, open Settings → Profiles, choose or create the profile for the patient, and tap Import Boards. Choose the file and wait for the import to finish.

The file works with the app on supported Apple, Android, and Amazon Fire devices. The boards are added to the profile you choose. If a board has the same name as one already there, the imported board replaces it. Save a copy first if you need to keep the existing board.

Remember

  • Save a new copy after making important changes.
  • Keep a copy somewhere other than the device.
  • Before restoring, save a copy of any boards on the device that you want to keep.
  • Do not tap Delete All Data to make a backup. It permanently deletes data and cloud backups.

A good habit: keep a recent backup somewhere safe, so the person's communication boards are ready when needed.
